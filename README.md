# 红利低波数据看板 · 东方财富数据


## 本地运行与验证

当前页面读取 `public/data/` 静态快照，无需 Python 后端或服务密钥。推荐 Node.js 22，与采集工作流一致。

```powershell
npm ci
npm run dev
```

构建及离线验证：

```powershell
npm test
npm run calendar:check
npm run build
npm run preview
```

Python 仅用于指标／成分股采集及其测试，工作流使用 Python 3.13：

```powershell
python -m pip install -r scripts/requirements-indicators.txt
npm run test:collectors
```

本地验证 Worker：先执行 `npm run build`，再执行 `npm run dev:worker`。发布到已配置的 Cloudflare 账号使用 `npm run deploy`；只检查部署产物可执行 `npx wrangler deploy --dry-run`。这些操作不部署 Python 服务。现有 GitHub 集成也可在数据提交后构建并部署页面，其远端状态须单独核验。

日常更新使用 `npm run data:refresh-market`、`npm run data:refresh-indicators`；这两个命令访问上游并写入本地数据及状态。`npm run data:constituents` 单独更新成分股；`npm run data:metrics` 仅用已有快照计算指标。`data`／`data:update` 是原始行情采集诊断入口，不负责统一状态编排。

## 交易日历维护

运行 `npm run calendar:check` 检查日历结构、逐年来源和覆盖期限。到期前 90 个自然日内发出警告，覆盖到期当天仍有效；超出覆盖或结构异常时返回非零退出码。两套采集工作流均运行此检查，检查失败不阻止采集及成功数据提交，最后将任务标记失败。

当前覆盖 2023–2026；2026-09-29 核验的上交所官方页面仍列出 2026 年安排，未找到可确认的 2027 年公告，不预填下一年休市日。具体更新步骤、核验来源和跨年验收见 [交易日历维护](docs/trading-calendar-maintenance.md)。这项检查只核对本地覆盖，不自动抓取或确认官方公告。

## 看板功能

首页按“关键指标 → 指数／ETF K 线 → 回撤曲线 → 观察提醒 → 收益与风险 → 收益风险对比 → 低波特征分析 → ETF 分红与收益（仅 ETF）→ 定投模拟器 → 估值分析 → 成分与行业结构 → 数据说明”排列，侧栏导航使用相同顺序。K 线与回撤上下排列，优先呈现走势和风险。

「定投模拟器」用相同初始预算比较一次性买入、每周／每月定投和指定批数／间隔的分批投入。支持自定义区间、投入日期、整手／理想小数份额及买入费用，展示总资产曲线、盈亏、剩余现金、总预算收益率、总资产回撤和逐笔明细。ETF 可计入已核验分红与拆分，指数页明确为理论价格模拟；未执行计划不提前投入，分红不再投资。假设与计算说明见 [定投模拟器](docs/investment-simulator.md)。

「自定义观察提醒」支持按证券设置价格、当前回撤跌幅、PE/PB 的 ≤／≥ 条件，以及编辑、暂停和删除撤销。满足条件时首页显示提示，保存触发值、数据日期及检查时间；持续满足和重新打开不会重复记录。规则及最近100条触发记录保存在当前浏览器，关闭页面后不主动通知。异常、较旧或日期倒退的数据标为待核验，不产生新触发；ETF 的 PE/PB 使用 H30269 标的指数估值。口径和运行范围见 [自定义观察提醒](docs/observation-alerts.md)。

首页「低波特征分析」跟随当前选择的 H30269／512890，复用已有日线。提供 20／60／120 个交易日日收益的滚动年化总波动率与下行波动率、月度价格收益热力图、最差完整月份前五名，以及主要回撤事件的高点、低点、恢复日期和时长。支持全部已核验历史、近1年、近3年和年初至今；未结束的月份标为月内收益，不参与最差月份排名。ETF 使用未复权价格，不含现金分红。公式、日期验证和测试说明见 [低波特征分析](docs/low-volatility.md)。

首页增加「收益与风险对比」，固定比较 H30269 红利低波与 000300 沪深300的价格指数，不含分红再投资。提供累计收益、区间回撤、60个交易日日收益的滚动年化波动率及区间指标表；支持年初至今、近1年、近3年、全部共同历史和自定义日期。按同一起点、共同截止日及交易日历验证，不补缺失行情。任一侧读取失败保留整份上次对比输入和日期。首次基准采集可用 `npm run data:benchmark -- --bootstrap`，日常行情工作流已纳入000300。公式、数据源、更新与验证见 [收益风险对比](docs/index-comparison.md)。

首页行情图下方提供当前证券的回撤曲线，使用同一份已同步日线收盘序列，不增加数据请求或数据源。展示当前回撤、最大回撤的高点／低点日期与价格，以及最大回撤是否恢复、首次恢复日期和从高点起的自然日时长。回撤为 `收盘价 / 截至当日最高收盘价 - 1`，曲线显示非正百分比；收盘价等于原高点即视为恢复，并用最近一次同价高点作为下一轮回撤起点，最大跌幅相同时保留首次发生的事件。没有回撤时显示 0%／无需恢复，少于两个样本时不展示误导性的回撤值。

回撤统计注明实际已同步历史起止及样本数，不填补缺失交易日，不代表成立以来或盘中回撤。512890 使用未复权价格，不含现金分红，除息也可能形成价格回撤；H30269 使用价格指数，不含分红再投资。收益风险摘要仍为 H30269 保存的统一指标，其日期和范围可能与本图不同。滑块和拖动只改变查看区间，高点及摘要仍以全部已同步历史计算；行情刷新保留按日期选择的区间，读取失败保留原曲线和日期。侧栏“回撤曲线”可直接定位。

功能口径、实现文件、验证结果及提交记录见 [回撤曲线与恢复分析](docs/drawdown.md)。

K 线工具栏增加「观察笔记」和「导出 PNG」。笔记按证券保存在当前浏览器，可填写日期、可选价格，或在全屏图上选择位置；支持编辑、定位、删除撤销，以及全部笔记 JSON 备份导出／导入合并。PNG 保留当前图形、指标、可见画线与笔记标记，并注明证券、实际查看区间、行情来源和数据日期。入口、保存范围及限制见 [观察笔记与图表导出](docs/notes-export.md)。

512890 页面新增「ETF 分红记录与含分红收益」，分别展示价格收益、实际现金分红权益，以及现金不再投资的含分红收益。数据使用独立的分红／拆分快照，不能用 H30269 指数股息率代替 ETF 分红。采集命令为 `npm run data:etf-distributions`；来源核验、公式、除息／到账及拆分处理见 [ETF 分红与收益口径](docs/etf-income.md)。

证券选择和 K 线使用偏好自动保存在当前浏览器的本地存储中。同一站点重新打开后恢复上次选择的证券；H30269 与 512890 分别保存日／周／月／季周期、K 线或折线、MA 的周期／显示／颜色／线宽、BOLL／BBI 的显示状态、副图指标及各指标参数。顶部“恢复默认”重置两只证券的全部偏好，并选择默认的 512890、日线、K 线和 KDJ；已保存的画线保留。指标参数弹窗中的“恢复默认”仍只恢复当前表单，点击应用后才生效。

这些偏好只在当前浏览器、当前站点生效，不跨设备同步，不需要新数据源。无效或旧版本配置回退默认；浏览器禁止存储或写入失败时提示无法保留设置，仍可继续切换和查看行情。

首页价格卡显示当前证券日涨跌额、涨跌幅及行情所属年份的年初至今价格表现。日涨跌以准确的上一交易日收盘价为基准，年初至今以该年份之前最后一个交易日收盘价为基准；缺少基准或日历覆盖时明确提示，不用年内首条行情代替。ETF 使用未复权价格，指数使用价格指数，均不包含分红再投资；显示基准及截止日期，读取失败保留原值与日期。首页“查看成分股”直接打开全屏图表的成分股页，ETF 页面标为“标的指数成分股”。

首页回撤曲线之后提供「收益与风险」摘要，直接展示 H30269 的年化收益率、最大回撤和夏普比率。与全屏侧栏复用统一指标文件、格式化和口径说明；512890 页面明确标注为标的指数表现。摘要保留计算区间、价格指数不含分红再投资及夏普无风险利率假设 0% 的说明，支持首页刷新、独立重试与读取失败保留旧值。桌面宽屏三列，窄屏单列。

## 首页数据状态

首页与全屏详情通过页面级 `useDashboardData` 共享行情、最新指标、收益率、估值历史及读取状态。同一来源的并发请求合并；打开或重新打开详情复用已读取的快照和错误，点击刷新／重试才重新读取。H30269 与 512890 行情按证券分别保存，迟到响应不会覆盖另一只证券。页面关闭后不跨页面保留缓存。

首页“重新读取”刷新当前证券及本页已使用的数据来源。最新指标、PE/PB 和股息率在本页已使用时一起重新读取；不同文件仍保留各自日期及独立失败状态，不保证跨文件为同一批次的部署快照。某个来源失败时，所有使用它的视图共同显示原值、原日期和读取失败提示。估值来源、统计范围、PE/PB 选择等视图设置仍由各视图独立维护。

首页区分浏览器文件读取状态、后台采集结果和数据时效。正常的来源日期差异使用中性说明；文件成功返回不会清除后台失败标记。“重新读取”仅获取已部署文件，不触发上游采集。

`npm run data:refresh-market` 与 `npm run data:refresh-indicators` 会生成 `public/data/dashboard-source-status.json`（schemaVersion 1），分别记录 H30269、512890、东方财富估值及历史、中证股息率、国债和中证估值历史的 `status`、`lastAttemptAt`、`lastSuccessAt`、`error`。两套工作流一起提交此文件；仅明确成功的来源清除自己的错误，失败保留上次成功时间。旧版失败记录可以迁入，但没有记录的采集时间保留 null，不从行情日期或文件修改时间推算。直接执行原始采集脚本不更新这份统一状态，应使用上述完整入口。

状态文件在首次完整更新后生成；不存在、损坏或读不到时，页面明确显示“后台采集状态未知”，继续展示可用数据。重新读取状态失败时，保留此前已知的失败记录并提示未能重新核验；不会把此前的成功记录视为当前已确认成功。页面时间为最近已部署记录，不代表尚未部署的后台运行结果。

数据时效独立判断：以现有 A 股交易日历为参考，行情在北京时间 17:30、其他指标在 19:15 后将当日计入，落后至少 2 个交易日显示“数据较旧”。这是包含工作流发布时间后 1 小时宽限的页面提示规则，不是来源服务时效承诺；国债也仅使用该观察参考，不冒充其官方发布日历。周末、已知休市日不累计；超出日历覆盖显示待核验。采集成功也可能返回旧日期，不能据此标记请求失败。

收益风险摘要另外保留统一指标自身的计算状态和计算日期。行情文件重新读取失败时保留已有图表与原日期，首次没有有效数据时显示错误与重试入口。

## 右侧估值分析

首页及估值详情提供「历史积累与覆盖」概览，显示所选统计范围内的有效日样本数、实际起止日期、自然日跨度和距离 20 个样本最低计算门槛的进度。首页分别读取东方财富 PE/PB 与中证总股本 PE 的历史，独立展示，不能相加或拼接。中证不提供 PB。样本不足时显示“样本积累中”，不展示空白分位和分位线；达到门槛后仍明确提示当前样本不代表长期估值水平。进度不是完整历史覆盖率，也不预测补齐日期。

切换近一年、三年或五年时，样本进度和覆盖区间按所选窗口更新；历史未覆盖所选范围时直接提示。重新读取失败保留已显示样本和覆盖范围，中证读取失败不影响东方财富摘要。最少样本数由统计计算和界面共用同一常量。

K 线放大视图的「简况 → 指数分析」中，PE / PB / 股息率下方展示估值小图，「放大」打开独立弹窗；Esc 先关闭估值弹窗，保留 K 线全屏。大小图共享来源、口径和范围，滑块只改变可视区间。

默认来源是中证官方，默认范围是「全部已积累」，默认展示 P/E1（总股本口径）；也可切换 P/E2（计算用股本口径）。二者采用官方 XLS 字段值，未确认财报周期及与 factsheet 滚动 PE 的对应关系，不标注 TTM。中证文件没有 PB，因此中证视图只展示 PE。切换东方财富后可查看原有 PE/PB；上方最新 PE/PB 卡片仍使用东方财富，并明确显示来源。512890 展示 H30269 标的指数估值。

- `public/data/valuation-history-csi-h30269.json`：中证独立历史，保存 `peTotal`、`peCalculation`（倍）、`dividendTotal`、`dividendCalculation`（百分数）。本次初始化包含 2026-08-28 至 2026-09-24 的 20 个交易日。
- `public/data/valuation-csi-status-h30269.json`：记录最近尝试时间、最后成功获取时间与更新状态；成功获取时间不是最新交易日。
- `public/data/valuation-history-h30269.json`：原有东方财富历史，保持独立，不与中证拼接。

`npm run data:refresh-indicators` 复用一次中证文件下载，独立解析股息率快照与估值历史；合并文件返回的全部记录，按日期去重并覆盖修订值，保留窗口外已保存数据。来源、字段、日期、数值或本地历史异常时保留原历史，状态文件标记失败；其他来源继续更新。GitHub Actions 提交中证历史和状态文件，失败时也尝试提交其他已成功更新的数据。不会伪造、插值或自动补齐窗口外漏失的交易日。

统计范围以最新估值日期为终点，分位数采用线性插值，排名采用 `(小于当前值数量 + 等于当前值数量 × 0.5) / 样本数 × 100%`。不足 20 个样本不计算分位；全部或覆盖不足时显示「已积累区间分位」，并标明实际覆盖日期与样本数，不代表完整一年或成立以来历史。

当前首页行情由东方财富 K 线文件提供，PE / PB 由东方财富旗下天天基金的 H30269 指数估值接口提供，股息率使用中证 H30269 的 D/P1（总股本口径），中债继续提供十年期国债收益率。Worker 保留旧版兼容 API，不参与当前首页取数；历史说明见 [旧 AKShare 架构归档](docs/archive/akshare-service.md)。

本地预览只需 `npm ci`、`npm run dev`，读取 `public/data/` 已生成数据。

## H30269 / 512890 / 000300 数据更新

GitHub Actions 在每个工作日北京时间 16:30（UTC 08:30）运行 `npm run data:refresh-market`，更新
`public/data/h30269.json`、`public/data/512890.json` 和 `public/data/000300.json`，随后生成 H30269 统一最新指标。三只证券分别刷新最近 30 个自然日、回补一个 90 天窗口，并保存独立游标。数据有变化时一起提交行情、统一指标和来源失败状态 JSON，commit 信息为
`chore(data): update market data`；没有变化时不产生 commit。

执行时先分别更新并保存三个标的的近期行情，再回补历史，阶段之间间隔 3 秒。近期行情失败会保留旧数据、跳过该标的本轮回补，并将任务标记失败；其他标的继续处理。仅历史回补请求失败时给出 Actions 警告，保留回补游标，下次继续，不影响已保存的近期行情。文件读写或校验异常仍标记失败。网络失败日志附带可用的底层错误码（例如 `ECONNRESET`、`ENOTFOUND`），用于排查连接或 DNS 问题。失败任务仍会尝试提交已成功更新的数据。

需要手动执行时，进入 GitHub **Actions → Update H30269, 512890 and CSI300 → Run workflow**。GitHub Actions
只负责数据更新与提交；Cloudflare 仍由原有 GitHub 集成在检测到新 commit 后负责 Build 和 Deploy。

## 指标采集

### PE / PB 与十年期国债收益率

`python scripts/fetch-indicators.py` 独立更新以下数据（中证 XLS 解析依赖 `xlrd==2.0.2`）：

- `public/data/valuation-h30269.json`：东方财富 / 天天基金 `FundSpecialZSB30ZSIndex` 接口，指数代码校验为 H30269；`Petim` 为 PE、`PB` 为市净率、`PDate` 为估值日期。保存原始精度，页面显示两位小数。未确认 TTM 和加权口径，不能标为 PE-TTM，也不与其他来源历史数据拼接。此接口不提供股息率。
- `public/data/dividend-h30269.json`：中证 H30269 每日指标文件的 D/P1（总股本口径，百分数），512890 与 H30269 共用此指数股息率，显示原始数据日期与来源，不代表 ETF 实际现金分红收益率。
- `public/data/china-bond-10y.json`：中债国债到期收益率曲线的 10 年期限值。

512890 页面明确标为“标的指数 PE / PB”，展示 H30269 指数估值。各项独立显示数据日期和来源。历史分位暂不接入，因为上游分位的计算区间未确认。

### 2. 统一统计窗口

收益、回撤和夏普使用一个窗口，独立于 K 线日／周／月切换、缩放、鼠标悬停和选中区间。

1. `T` 为已同步的 H30269 最新有效日线日期，按中国市场日期处理，不以打开页面当天作为收益截止日。
2. 起点 `S` 为当前已同步历史中的第一条有效日线日期。使用全部历史，不再从 T 向前截取一年，也不随 K 线可见区间改变。
3. 取 S 至 T 的全部日收盘价，首尾都包含；校验整个区间的预期交易日，缺日或坏数据不静默跳过。
4. 至少两个收盘点才能计算年化收益和回撤；夏普至少需要两个日收益观测且波动非零。不足一年仍按实际自然日年化，页面额外提示“历史不足一年，年化结果仅供参考”。
5. 展示“全部历史”及实际起止日期。“全部”仅指当前已同步的数据，不代表指数成立以来；补入更早数据会重新计算三项，不同起点的指数结果不宜直接横向比较。

价格序列不含现金分红再投资，不包含 ETF 管理费、交易成本或跟踪误差。页面公共说明使用“全部历史 · 价格指数（不含分红再投资）”。

### 3. 公式

设窗口收盘价为 P[0] 至 P[n]，n 是收益观测数，D 是 S 至 T 的实际自然日差。计算保留原始精度，最后显示时再舍入。

#### 年化收益率

`annualReturn = (P[n] / P[0])^(365 / D) - 1`

使用 ACT/365 固定年基准；跨闰年仍使用 365，不切换成年内交易日条数。此规则是项目约定。恰好 365 天时等于区间累计收益，不用日收益算术均值代替。

#### 最大回撤

`peak[i] = max(P[0], ..., P[i])`

`drawdown[i] = 1 - P[i] / peak[i]`

`maxDrawdown = max(drawdown[0], ..., drawdown[n])`

仅用日收盘价，不混用最高价／最低价。峰值限定在当前窗口；窗口外峰值不纳入。记录对应峰值和谷值日期；相同峰值取最早日期，相同最大回撤取最早谷值，无回撤时为 0，峰谷日期可为 null。

#### 夏普比率

`r[i] = P[i] / P[i-1] - 1`，i=1,...,n。

首版 `annualRiskFreeRate = 0`，`dailyRiskFreeRate = 0`，`x[i] = r[i] - dailyRiskFreeRate`。

`mean = sum(x[i]) / n`

`sampleStd = sqrt(sum((x[i] - mean)^2) / (n - 1))`

`sharpe = sqrt(252) * mean / sampleStd`

- 日收益使用简单收益率，标准差使用样本标准差（n−1）；252 是固定年化参数，不随当年交易日数量变化。
- 无风险利率固定为 0% 是可复现的基准假设，并不代表市场实际利率；与采用同期存款／国债利率的平台不可直接比较。
- 页面必须在夏普附近可见地标注“无风险利率假设 0%”，不能只藏在说明弹窗。夏普数值不乘 100，不加百分号。
- 不使用“几何年化收益率 ÷ 年化波动率”替换此公式。
- `n < 2` 或 `sampleStd <= 1e-12` 时夏普显示“—／样本不足或波动为零”，不输出无穷大；不影响有效的年化收益和回撤。
- 后续若采用非零或历史利率，必须升级规则版本，明确利率期限、对齐及转换方法并重算，不静默改变现有定义。

夏普的均值／标准差基础定义参考 [William F. Sharpe, The Sharpe Ratio (1994)](https://web.stanford.edu/~wfsharpe/art/sr/sr.htm)。0% 基准、252 年化和本项目窗口是实现选择，不是论文对该指数的规定；平方根年化不作自相关修正。

### 4. 有效性、日期及缺失处理

- 数据身份必须为 H30269；严格校验日期、有限数值、重复日期和收盘价 > 0。允许排序但不静默丢弃坏记录、覆盖重复值或补零。
- 对当前窗口核对交易日历，不以“周一至周五”直接代替交易日。补班周末仍需按交易所日历判断。
- 起点、终点或窗口内预期交易日缺失，三项计算值均不发布新值；不跨缺失交易日当成一个日收益，也不前值填充或插值。
- 日历未覆盖窗口时，显示“交易日历待核验”，不假定完整。日历当前覆盖 2023–2026，补入更早数据或滚入新年份前须扩展官方日历。
- 本地文件中的 `latest` 与最后一条历史记录必须一致。T 不得为未来日期、休市日或尚未收盘的当日；全部日线为收盘数据。
- PE／PB 沿用现有快照的有限正数校验；收到非正值视为该源本版不支持的输入，不展示为正常估值。股息率使用百分数单位、有限且在 0–100 范围内，0 是有效值。
- 空字符串、null、布尔值不转换为 0；缺失值显示“—”。前端不显示 NaN、Infinity 或 -0.00。
- PE／PB 显示其 PDate，股息率显示中证原始日期，三项计算显示 S—T。抓取时间 `updatedAt` 不能冒充数据日期。
- 来源间不强行对齐或插值。某指标日期早于最新行情日期，提示“截至该日”；不把日期较旧等同于请求失败。
- 采集失败可以保留旧值，但显示“更新失败，保留上次数据”和原日期。旧计算结果须整体保留原窗口、版本与状态，不可挂在新的 T 下。
- 无旧值时显示“暂无数据／原因”。坏数据不能覆盖旧的有效快照。单项失败不遮挡其他有效指标。
