# 分红质量与基本面分析

首页和侧栏「分红质量与基本面」位于成分结构分析之后。H30269 与 512890 页面均可查看；ETF 页明确展示标的指数成分股，不代表基金实际持仓。

## 年度与数据

按采集时已结束的最近五个财年展示，首次快照为 2021—2025 年，名单日期 2026-09-30。分红按所属报告财年归集，与同一年年报归母净利润、经营现金流对齐，不使用实施日期所在自然年替代，不用半年报、单季度或 TTM 数据补年报。

来源为东方财富数据中心，静态快照保存于 `public/data/fundamentals-h30269.json`：

- [分红送配与分红融资资料](https://data.eastmoney.com/yjfp/)：`RPT_F10_DIVIDEND_HISTOGRAM`，`DIVIDEND_IMPLE` 为该财年已实施公司现金分红总额；`DIVIDEND_PLAN` 单独保存作实施进度参考。
- [财务分析](https://emweb.securities.eastmoney.com/PC_HSF10/FinanceAnalysis/Index?type=web&code=SZ000001)：`RPT_F10_FINANCE_MAINFINADATA`，保留年报 `PARENTNETPROFIT` 归母净利润、`NETCASH_OPERATE_PK` 经营活动现金净流量、`ROEJQ` 加权净资产收益率，以及公告／修订日期和来源企业类型。
- 名单及行业复用中证 H30269 名单和已保存的中证一级行业匹配结果，日期不一致或匹配不到时行业留空；未分类单列，不推断分类。

财务币种须为 CNY；金额统一为人民币元，界面缩放为亿元。公司分红总额可以包含来源统计的其他上市股类，不是该 A 股每股分红。归母净利润与合并经营现金流存在报表范围差异，原值与日期可在个股历史中核对。来源为空字段、年度缺失、更新失败和明确零值分别保存。

首次快照覆盖 50 只股票的 2025 年分红金额；2021 年有两只股票缺少该来源的 A 股分红年度记录，不按零分红处理。首次完整五年窗口的连续性可判定 48 只；这些数量随真实快照更新重新计算，不固化为长期结论。

## 连续性、增减与覆盖

从所选财年向前逐年检查已实施分红，正金额表示已分红。遇明确零值停止；遇缺失年度停止并标为年数下界，当前年缺失则显示待核验。检查完整窗口时，只有全部年度金额已知才判定连续或中断。观察窗口全部为正显示“至少 N 年（限观察窗口）”，不声称上市以来连续分红。

总额同比 = 当年已实施总额 / 上年已实施总额 − 1。只使用相邻财年，不跳过缺失年度。前期零值、当期正值标由零转正，两个零值标连续零分红，均不生成百分比增长。金额变动在 `max(1 元, 上年金额 × 1e-8)` 内视作持平，以处理来源数值舍入。

计划金额比已实施金额高出 `max(1 元, 计划金额 × 1e-8)` 时标为实施待完成；其已实施金额可查看和汇总，但不纳入完成状态的增减分布或同样本同比汇总。后者使用两年金额都已知且无待完成标记的同一组公司，汇总金额后相除，不平均个股增长率。

- 分红支付率 = 已实施现金分红 / 同年归母净利润，归母净利润须为正。
- 利润覆盖倍数 = 同年归母净利润 / 已实施现金分红，分红须为正。
- 非金融现金流覆盖倍数 = 同年经营现金流 / 已实施现金分红，分红须为正。

覆盖 ≥ 1 仅表示该口径下该年度金额足额。负利润、负现金流保留负覆盖值；零分红不生成无穷大覆盖，缺少任何所需值不生成比率。摘要分别给出可计算样本分母，不把缺失样本放入“足额”计数。

中证行业为金融，或来源企业类型为银行、证券、保险、金融、信托的股票，保留原经营现金流，排除通用现金流覆盖比较。经营现金流未扣资本开支，不是自由现金流或可分配现金；本项也不是未来分红保证。

## 行业和个股贡献

个股占比 = 该公司所选财年已实施分红总额 / 全部已覆盖公司分红总额；行业占比将同一行业公司金额相加后除以同一分母。金融企业、未分类均计入金额分母。金额未知的股票不被当作零，汇总注明金额覆盖数量；无任何已知金额时总额和占比均不可用，明确全为零时总额为零、占比不可计算。

这些是公司分红总额的规模分布，不是指数股息率、权重加权分红贡献、指数收益贡献、ETF 分红或个人收益。当前快照名单和行业被用于回看过去财年，存在成员选择偏差，不构造历史时点成员回测，也不推断持仓权重。历史成员观察见独立的成分结构模块。

## 查看、筛选与导出

可按财年、行业、代码／名称筛选，再筛选分红总额减少、归母利润不足覆盖、非金融现金流不足覆盖、完整窗口连续分红，或缺字段／年度／保留值；可按金额、总额同比、连续年数、利润覆盖排序，空值放在末尾。

点击「年度历史」查看截至所选财年的分红、计划金额、归母利润、经营现金流、ROE 和年报公告／修订日期；每只股票分红与财务来源分别显示最近成功与尝试时间。表格在内部滚动，窄屏不使整页横向溢出。

「导出分红基本面 CSV」导出当前筛选结果，含财年、名单日期、原始元金额、同比、覆盖、贡献、连续性下界及来源状态／成功时间。UTF-8 BOM；缺失单元格留空，股票代码和文本加引号，可能被表格软件解释为公式的文本前加单引号，负数金额仍保留数值。

## 采集与失败保留

运行 `npm run data:fundamentals`，无新依赖或服务密钥。每只股票分红及年报各请求一次，三路并发；单次超时最多 20 秒，整轮网络采集最多约三分钟，剩余来源失败保留待重试。请求按股票代码和交易所、固定年度范围过滤，验证响应成功、完整分页、证券身份、币种、日期、重复年度及有限数值。相同财年允许上游修订，原已保存年度消失则拒绝该来源更新。

每个股票的两个来源独立保存 `ok`／`stale`／`unavailable`、失败原因、最近尝试和最近成功时间。失败保留原记录及原成功时间，首次失败不创建零记录；一只股票失败不擦掉其他成功记录。新成员没有旧数据时保持不可用，移除成员不混入新名单。名单读取失败或日期倒退时保留整份原名单与原数据；损坏的本地基本面文件拒绝覆盖，须先核验。年份滚动只保留新窗口内旧记录，尚未披露的新年度明确缺失。

数据在指标工作流中、名单更新之后采集；成功或保留结果一起提交，任何个股来源失败最终使工作流标记失败，其他成功更新继续保存。行业源读取失败时基本面仍可更新，分类留空；总体来源采集成功不代表所有年度字段均完整。

页面重新读取仅获取站点快照，浏览器不直接请求上游。已使用的基本面、名单、行业历史刷新合并并发请求。界面在读取结束后采用完整输入组；文件读取失败保留原分析及原日期。基本面名单与当前名单日期或成员不一致时明确提示，只分析基本面档案内的原成员，不套用到新成员。首次无快照显示不可用，不伪造金额与覆盖。
