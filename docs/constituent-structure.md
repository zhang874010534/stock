# 成分股变化与行业结构

首页与全屏成分股页共用 H30269 名单及行业历史。首页可查看行业股票数量、数量占比，点击行业或搜索代码／名称筛选股票，选择历史观察查看当时的名单与分类，并查看相邻观察的调入调出、名称更新和行业归属变化。512890 页面展示其标的指数样本，不代表 ETF 实际持仓。这里没有权重数据，数量占比不代表指数权重或资金配置比例。

## 数据来源与覆盖

名单来自[中证 H30269 官方样本 XLS](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/cons/H30269cons.xls)，保存于 `public/data/constituents-h30269.json`。页面分别标出文件来源日期和采集观察时间。

行业采用[中证全指行业指数编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/H30199_Index_Methodology_cn.pdf)列出的 11 个一级行业指数，逐一下载其官方样本文件，按交易所与证券代码匹配。行业指数自身有选样筛选，不能作为覆盖所有上市公司的完整行业字典；未匹配股票保留在 H30269 中并计入「未分类」。

各行业文件地址使用与 H30269 相同的官方路径，例如[金融行业样本](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/cons/932083cons.xls)。每只股票保存匹配来源指数、行业文件日期、分类观察时间及状态，页面提供来源文件链接。行业文件日期可以不同，也可能与 H30269 名单日期不同；分类代表这些来源的观察结果。

2026-10-01 的采集匹配到 2026-09-30 名单中的 45 / 50 只，共 9 个行业；江阴银行（002807）、张家港行（002839）、中国国贸（600007）、厦门银行（601187）、重庆银行（601963）未匹配。数量占比始终以全部 50 只为分母，未分类也占一组。全部来源请求成功但覆盖不全标为 `partial`，并不是采集请求失败。

## 历史与时间线

历史文件 `public/data/constituents-history-h30269.json` 使用 schemaVersion 1，记录来源及状态、最近采集尝试时间、按观察时间递增的 `snapshots`。每份观察包含名单来源日期 `date`、采集时间 `observedAt` 和完整 50 只股票。分类字段为 `industry`、`industryDate`、`industryObservedAt`、`industrySourceIndex`、`industryStatus`；没有分类时字段为空，状态为 `unavailable`。

初始四份观察直接取自项目 Git 中已保存的真实 JSON，保留其 `updatedAt` 作为观察时间，不以 Git 提交时间替换。此前未采集行业，四份旧名单的行业均未分类。

时间线按交易所和代码识别股票：新增代码为调入，消失代码为调出；同一代码名称变化单独显示，不计入调入调出。只有前后均已分类且行业不同才显示行业归属观察变化，首次补充分类不算调样。第一份观察仅作基线，不产生「调入 50 只」事件。

历史观察只使用其自身保存的分类。今天的分类不会回填旧名单；记录中的来源日期和观察时间也不能确认官方调样生效日。两次采集之间发生又撤销的变化无法由这些快照发现，更早的官方历次调样没有完整来源，页面不补造记录。

## 采集和失败处理

运行 `npm run data:constituents`。采集脚本先验证现有档案，再读取 H30269 名单和 11 个行业指数文件，最多 4 个并行行业请求。校验文件结构、指数身份、真实日期、六位代码、交易所、去重及样本数量；拒绝未来日期、来源日期倒退、冲突行业归属和损坏档案。行业指数允许北交所证券，目标 H30269 校验仍限定沪深市场。

名单失败时保留原名单、原日期及历史，状态标为 `stale`，不继续抓取行业。部分行业请求失败时，可保留此前已知分类及原分类日期／观察时间，标为 `stale`；无可靠分类则留空。行业请求全部成功后仍未匹配的股票恢复为未分类，不把旧匹配当作新来源。名单或行业请求失败返回非零退出码；仅覆盖不足返回成功。历史使用临时文件原子替换，已有档案校验不通过时拒绝重置或覆盖。

工作流 `update-indicators.yml` 已纳入历史文件的自动提交路径，推送配置后按原采集计划积累。页面「重新读取」仅读取已部署静态文件，不触发上游采集。首页与全屏页通过共享数据存储合并读取；首页刷新时等两份文件读取结束后整体更新分析，读取失败保留上次分析与原日期。名单和档案日期／内容不匹配时，不套用不对应的分类。

## 验证

Node 测试覆盖数量占比、未分类、历史隔离、名称更新、同日修订、调入调出识别、日期／来源校验、读取失败保留、名单与历史成对更新，以及首页／全屏共用请求。Python 测试覆盖行业 XLS、北交所条目、归属冲突、采集失败保留、初始历史积累、同日修订和损坏档案保护。

验证命令为 `npm test`、`npm run test:collectors` 和 `npm run build`；当前分别通过 212 项 Node 测试（另有 1 项既有跳过）、19 项 Python 测试及生产构建。浏览器检查行业筛选、股票搜索、历史未分类观察、全屏成分股入口、ETF 标的说明及手机布局。
