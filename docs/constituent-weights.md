## 采集、失败与维护

```powershell
python -m pip install -r scripts/requirements-indicators.txt
npm run data:weights
```

`scripts/fetch-constituent-weights.py` 独立采集两份数据，保存 `public/data/weights-h30269.json` 和 `public/data/holdings-512890.json`。指标工作流在名单更新后运行，成功与失败状态文件均纳入已有数据提交步骤；任一来源失败最终使工作流失败，但另一来源仍继续采集与保存。

ETF 从[上交所基金公告](https://www.sse.com.cn/disclosure/fund/announcement/)的公开查询接口读取，按不超过 90 天的窗口向前查找最新完整中期／年度报告（最多五个窗口），排除季度前十大报告及联接基金。校验公告代码、标题、官方 PDF 地址与披露日期；解析完整指数投资与积极投资明细，核验顺序、六位代码、交易所、股数、市值、报告权重与净资产、全部明细市值与报告股票资产合计。列结构或 PDF 文字结构变更、记录缺失及合计不符时拒绝覆盖。

指数必须恰有 50 个唯一成分、统一有效日期、权重为正，合计须在三位小数百分数舍入容差内；来源日期不允许倒退。ETF 允许明细数随报告变化，但必须通过完整合计检查。保存 `lastAttemptAt`、`lastSuccessAt`、`status`、`reason`；失败保留原值、原日期与成功时间，标记 stale，首次失败标记 unavailable。已有快照损坏时拒绝覆盖。

页面两份权重输入在请求完成后一起替换；一侧读取失败保留上次整组对照，显示错误和原日期。刷新关联已使用的成分名单／行业参考与权重／ETF 持仓；浏览器读取共享页面缓存，刷新不会触发上游采集。来源日期不同为公开披露频率说明，不按每日行情时效自动报错。

验证使用 `npm test`、`npm run test:collectors` 和 `npm run build`。新增用例覆盖真实合计、舍入小额股票、未分类权重、完整范围验证、跨日对照、搜索筛选、首次缺失、成组失败保留及采集日期倒退。已实测官方 XLS 和报告采集、桌面与手机布局、筛选及 CSV 生成与下载触发，自动用例另核验导出文件内容；远端工作流尚未运行核验。
