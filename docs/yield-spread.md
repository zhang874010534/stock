# 股息率与国债收益率差值

首页「股息率与国债收益率差值」及侧栏「股息与国债差值」展示 H30269 中证 D/P1 总股本口径股息率与中债十年期国债到期收益率，ETF 页明确使用标的指数数据。

## 计算与日期

- 两项原始值单位均为 percent，4.39 表示 4.39%。差值为股息率减国债收益率，单位为**百分点**；1 个百分点等于 100 个基点。
- 只对数据日期相同的观察计算，不用 updatedAt 对齐，不前向填充、不插值。已保存观察某日缺少一项，图表保留断点和明细“—”；未保存日期不补造。
- 最近差值使用全部历史中最近的同日样本，并展示该日期。最新两项日期不同时，各自展示原日期，提示不相减。
- 变化为最近同日差值减上一同日差值，显示两次日期，不称为日涨跌。单样本变化为“—”；无同日样本不显示 0。
- 日期筛选影响图表、区间均值／极值及表格，最近差值卡片始终使用全部历史。均值按同日观察等权，极值并列保留最早日期。图表缩放只影响视窗。
- 指数股息率不是 ETF 实际分红收益率；与国债收益率口径、风险不同，差值不是投资回报或交易信号，不修改现有夏普无风险利率假设。

## 历史与更新

`public/data/yield-history-h30269-cn10y.json` 分别保存两项观察，固定来源、证券身份和单位。历史基线由 Git 真正提交的原始快照恢复，当前从 2026-09-08 起，有 15 个同日样本及 1 个未匹配日期；不表示这之前无数据，不表示连续的市场历史。同一来源同日修订替换旧观察。

```powershell
# 首次恢复已提交的真实快照，再合并当前文件（历史深度取决于本地 Git）
npm run data:yield-history -- --seed-git
# 日常只追加本地最新有效文件
npm run data:yield-history
# 正常采集入口已自动追加历史，失败来源不参与本次追加
npm run data:refresh-indicators
```

历史写入校验元数据、真实非未来日期、非负有限百分数、排序及唯一性。来源日期倒退不覆盖，历史损坏停止写入；单项失败保留该项历史，另一成功来源仍追加，允许暂时日期不同。原子写入，内容不变不重写。后台 `yieldHistory` 状态独立记录历史写入失败和恢复，工作流提交列表已包含新历史文件，进入远端默认分支后生效。

前端复用首页 shared dashboard store 的股息率、国债文件，并增加一个历史文件请求。使用差值模块后，三项作为刷新组；任一文件读取失败或快照落后于历史文件，保留整组上次分析输入及日期。来源采集失败／未知和数据较旧分别提示，成功读取不宣称上游最新。重新读取不触发采集。
