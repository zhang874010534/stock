# 首页指数 K 线

首页继续通过 `src/api/h30269.js` 读取 `public/data/h30269.json`，将已加载的完整日线传给 `IndexChart.vue`。周期、均线、副图和时间范围均在前端切换，不额外请求数据。

## 文件职责

- `src/views/Home.vue`：保留行情加载、刷新、错误状态及其他首页模块。
- `src/components/IndexChart.vue`：组合工具栏、当前行情、副图读数及图表状态。
- `src/components/kline/KLineToolbar.vue`：周期、日期范围、MA 勾选和副图选择。
- `src/components/kline/KLineQuote.vue`：鼠标所在 K 线的 OHLC、涨跌、成交量和均线数值。
- `src/components/kline/useKlineChart.js`：单一 ECharts 实例、懒加载、缩放、十字光标和 ResizeObserver。
- `src/components/kline/useKlineFullscreen.js`：移动同一图表到全屏容器、ESC、焦点与滚动恢复。
- `src/utils/kline.js`：保留原有校验和周/月聚合，增加季度聚合、默认视窗和行情读数。
- `src/utils/indicators.js`：独立 MA、KDJ 计算。
- `src/charts/indexTrend.js`：ECharts 注册、三个坐标系、十字光标与 dataZoom。
- `src/charts/kline/config.js`：市场配色、MA 默认项、KDJ 参数、三图布局。
- `src/charts/kline/series.js`：主 K 线、成交量、均线及通用线序列工厂。
- `src/charts/kline/subIndicators.js`：副图注册项提供参数、计算、标题、读数和 series 工厂，目前注册 KDJ。

## 计算口径

- 周线按周一至周日，月线按自然月，季线按 1–3、4–6、7–9、10–12 月。每个周期使用首根开盘、末根收盘、最高价、最低价和累计成交量；日期标在该周期最后一个已同步交易日，顶部同时显示起始交易日。
- 历史回补未完成的首个周期、尚未结束的当前周期，仅包含已同步交易日。原始 JSON 不变，缺失的成交量也不会补成零。
- 先按完整已同步历史聚合，再计算指标，最后用 dataZoom 选择可见范围。保留原有“近1月”等按钮，但这些按钮现在只调整视窗，不截断周期或 MA 的计算历史。
- “最近”为默认视窗：日线 150 根、周线 100 根、月线 60 根、季线 40 根；不足时显示已有数据。可通过 slider 或滚轮缩放，并拖动任一绘图区平移。
- MA5/10/20 默认关闭，MA30/60 默认开启。MA 使用当前周期最近 N 根收盘价，不足 N 根时显示“—”。计算保留浮点精度，展示才保留两位小数。
- KDJ 默认 `(9,3,3)`：K、D 初值 50，前 8 根使用已有高低价窗口；窗口最高价等于最低价时 RSV 取 50；J 不截断到 0–100。参数独立配置，本阶段没有参数编辑界面。
- 涨跌及涨跌幅相对上一根同周期收盘价；首根没有前收盘价时显示“—”。鼠标离开图表后恢复最新一根行情。
- 成交量保留 JSON 原始数值，按万、亿缩写，不擅自换算为股、手或成交额。

## 手动验收

1. 执行 `npm run dev`，打开 Vite 输出的网址。首页最新点位、刷新和其他模块应仍正常；日线初始显示最近 150 根（历史不足时显示已有数据）。
2. 依次点击日线、周线、月线、季线，核对周期首尾、OHLC 和成交量。周/月/季历史较短时，MA30/60 显示“—”属于正常情况。
3. 打开 MA 菜单，确认默认仅勾选 MA30/60。依次开关五条均线，再全部关闭；曲线和顶部读数应即时变化，当前缩放范围保持不变。
4. 移动鼠标到主图、成交量和 KDJ 区域：纵线、日期和三个区域的读数应同步，鼠标所在区域显示横线和轴值；移出图表后顶部恢复最新行情。
5. 在三个区域分别滚轮缩放、左右拖动，再拖动 slider；三图时间轴应同步。点击“全部”可查看所有已加载历史，点击“最近”回到默认视窗。
6. 点击右上角“放大”，确认工具栏、行情、三图、slider 均可使用。用 ESC 和“退出”按钮分别测试退出；首页位置、滚动、均线和当前视窗应保留。
7. 在 1920×1080、2560×1440 和常见笔记本尺寸调整窗口，确认图表自动 resize、标签不重叠。

## 检查与范围

运行 `npm test`、`npm run test:api`、`npm run build`；部署兼容性可用 `npx wrangler deploy --dry-run` 检查。项目当前未配置 lint 命令或 ESLint/Prettier。

本阶段未实现 MACD、RSI、BOLL、分钟/分时行情、指标参数界面、复权、画线、筹码、资料、诊股或买卖信号。没有修改取数源、历史回补、GitHub Actions、Cloudflare Worker、部署配置或 JSON 结构。
