资料概要中的申购／赎回代理佣金上限不作为场内买卖佣金。费率是人工维护的资料快照，后续公告须人工核验并更新来源、资料日期、核验日期和数值，同时更新 `ETF_FEE_SOURCE` 与测试。管理／托管费只是部分运作费用，不代表全部综合费率。

规模注明最后尝试与成功时间，更新失败保留原报告期并标记 `stale`；无有效历史时为 `unavailable`，不使用零规模代替。报告期超过当前 180 天提示核验后续披露，此阈值仅是观察提示，不是法定发布期限。行情保留自己的日期、后台状态和交易日历时效说明。

## 流动性观察

支持近 30 个自然日、近一年、年初至今、全部可用历史、自定义日期。以最新已同步收盘日为截止，当前交易日尚未收盘时排除当日；自定义起点顺延、终点回退到交易日。区间基于已有 A 股交易日历，日历不覆盖则提示不可计算，全部历史只包含已同步且日历覆盖的日期。普通区间历史不足时截到可用起点并说明，自定义超出可用历史拒绝。

每日成交额与场内换手率在一张图的两个区域展示，日期和缩放同步；另附 20 日均线。20 日均值按连续 20 个实际交易日计算，可在区间前预热，不跨缺日改用较早记录，不缩短窗口。某个字段缺失仅使该字段均线不可用；真实零成交有效，缺失不当作零。区间均值、最低／最高和零成交天数只统计有效值，同时展示样本覆盖数。

截止日成交额相对 20 日均值使用包含当日在内的窗口。场内换手率直接展示来源值，不能用于反推报告期规模。规模图仅连接真实报告点，不补日度资产值。

CSV 以元导出成交额、以原百分数导出换手率，缺失字段／交易日与未形成的 20 日均值留空；表格显示亿元。文件注明日期区间，图表滑块仅改变查看范围，不改变统计区间。

## 成本情景

用户填写每笔交易金额 `A`（元）、佣金万分比 `c`、每笔最低佣金 `m`（元）、持有天数 `d`。佣金和最低收费不设假定默认值，需按自己的券商规则填写，可明确填 0。

- 单笔佣金：`max(A × c / 10000, m)`。
- 两笔等额买卖佣金：单笔佣金乘 2，假设买入和卖出金额均为 `A`；实际成交金额不同或券商规则不同需另算。
- 管理 + 托管费用参考：`A × (management + custody) × d / 365`，简化假设资产恒定、费率不变；不是账户额外收费，不与佣金相加作为实际支出。基金计提已反映在净值中，不从账本、净值分析或历史收益重复扣除。
- 单笔金额占 20 日均成交额：`A / amount20`，均额缺失或为 0 时不可用，以四位百分数显示。这只是订单金额相对历史成交量的比例，不预测冲击成本或成交概率。

不估算其他运作费用、交易相关税费、买卖价差或滑点。买卖价差明确显示未接入盘口；未来需另接同一时刻的买一／卖一价格及深度数据，不能用日内高低价振幅、成交额或换手率代替。成本假设仅存在当前页面，不修改真实账本或提醒。

## 维护

```powershell
npm run data:etf-size
npm test
npm run build
```

规模采集已纳入 `.github/workflows/update-indicators.yml`，成功或失败状态快照随数据更新提交；失败仍保留其他成功采集，最终报告不完整更新。只解析来源 JSON 赋值，不执行提供方 JavaScript，核对证券、单位、真实日期、有限数值及状态。来源只返回滚动窗口时，合并已有历史并覆盖同报告期修订；最新日期倒退拒绝更新。本地损坏档案拒绝覆盖。

页面重新读取仅获取站点快照，行情、规模、费率各自保存旧值和日期。规模失败不阻止成交分析更新，费率缺失不伪造零费率；重新读取不触发上游采集或人工费率核验。
