# 红利低波与沪深300收益风险对比

## 比较对象与入口

首页“收益与风险”下方新增独立对比区，侧栏“收益风险对比”直接定位。固定比较 H30269 中证红利低波动指数与 000300 沪深300指数；切换到 512890 时仍比较标的指数，并明确不代表 ETF 实际持有收益。

首版采用两只**价格指数**日线收盘，不含分红再投资，不使用 ETF 分红收益代替指数全收益。沪深300身份与价格／全收益区别见[中证编制方案](https://csi-web-dev.oss-cn-shanghai-finance-1-pub.aliyuncs.com/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000300_Index_Methodology_cn.pdf)。后续全收益比较须同时取得两边可核验的全收益序列。

默认近1年，可选年初至今、近3年、全部共同历史及自定义。摘要展示累计价格收益、最大回撤跌幅、区间年化波动率；收益差使用百分点。三张联动图展示累计收益、区间回撤及60个交易日日收益的滚动年化波动率。

## 日期与公式

- 共同最新日期取两只指数末日的较早值，同时显示两边各自的行情日期。
- 近1年／近3年从共同截止日向前对应周年，以该日或此前最近交易日为基准；2月29日在非闰年回退至2月28日。
- 年初至今以上年最后交易日收盘为基准，不以年内首条行情替代。
- 自定义开始日顺延、结束日回退至交易日；展示实际起止，不允许结束日期超过共同截止日或缺少所需基准。
- 全部共同历史从两只已保存行情及已核验日历的共同覆盖开始；当前日历为2023—2026，因此2022年已保存日线不进入完整比较。
- 按日历检查所选区间的所有预期交易日，缺日、额外非交易日、基准缺失或日历越界时停止完整比较。不能只取日期交集掩盖缺日，也不补价格／插值。
- 累计收益为 `P(t)/P(start)-1`，起点为0%；回撤为 `P(t)/max(P(start..t))-1`，只计算所选区间内高点。复用现有回撤算法，摘要以正数表示最大跌幅。
- 简单日收益为 `P(t)/P(t-1)-1`，年化波动率为日收益**样本标准差**乘 `sqrt(252)`，不足两个日收益时不展示数值。
- 滚动波动率固定使用60个日收益，即61个连续有效收盘。读取计算区间之前的已核验历史预热；预热缺日时清空连续窗口，积累足够样本后才恢复，不跨缺失日计算日收益，不用短窗口替代。

计算直接使用本模块两份行情，不读取首页已保存的“全部历史”风险摘要，二者范围和日期可能不同。历史回补会扩展全部共同历史，不能描述为成立以来。

## 采集与更新

沪深300复用东方财富日线接口，证券参数为 `1.000300`，`klt=101`、`fqt=0`，校验返回代码／市场、OHLC、日期、排序及去重，拒绝将510300 ETF或其他证券当作000300。

独立快照：`public/data/000300.json`，沿用现有行情结构及独立回补游标。2026-09-30首次真实初始化取得2022-12-01至2026-09-30的930条记录；这是有边界的已同步历史，`backfill.completed`仍为false。

```powershell
# 首次初始化，或重新合并这个有边界的历史窗口
npm run data:benchmark -- --bootstrap

# 独立更新沪深300，并记录该来源状态
npm run data:benchmark

# 日常完整行情编排：H30269、512890、000300
npm run data:refresh-market
```

三只证券都先更新近期，再依次回补历史，沿用请求间隔、重试与失败保留。`dashboard-source-status.json`新增000300来源；沪深300失败不把H30269的统一收益风险指标标为失败。独立初始化也只更新000300状态，保留其他来源记录。

行情工作流已有时间不变，增加沪深300文件的变化检测与提交。配置须进入远端默认分支才生效，本次未推送、部署或触发远端工作流。

## 刷新与图表

复用页面共享数据层，使用过对比后，刷新H30269或000300会一起读取两份文件。本模块等待两个读取完成再替换比较输入；任一侧读取失败时保留整份上次比较的输入及原日期，不能将本次成功的一侧静默混入旧结果。后台失败和数据时效仍独立显示，读取成功不清除后台失败记录。

切换证券不改变比较对象。切换计算区间重新计算并重置图表窗口；自定义在点击应用后生效。刷新按日期恢复查看窗口，缩放／拖动只改变可见区间。一个ECharts实例中的三个坐标系共用滑块、缩放和联动指针，缺少滚动波动率的地方留空。

图表组件动态加载并按需注册ECharts；使用ResizeObserver处理尺寸和隐藏更新，卸载释放图表与监听器。
