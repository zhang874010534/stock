# 观察笔记与图表导出

## 使用入口

K 线工具栏提供「观察笔记」和「导出 PNG」。首页小图和全屏图均可导出；点击「观察笔记」会进入全屏右侧「笔记」页签。点击图中黄色 N 编号也能打开对应笔记。

1. 填写日期和观察内容，价格可选。价格留空时，图上标记按该日已同步收盘价定位。
2. 可点击「在图上选位置」，再点击主图的日期／价格位置。选取价格按 ETF 三位、指数两位小数填写，仍可手动修改。Esc 或右键取消位置选择，下一次 Esc 才退出全屏。
3. 「保存笔记」自动保存到本机。列表支持编辑、定位和删除；「撤销最近一次删除」可恢复当前页面中最近删除的一条，刷新后不保留撤销记录。

笔记使用证券代码隔离：H30269 与 512890 分别显示，日／周／月／季图共用对应证券的同一份笔记。原始日期保持不变，周／月／季图将它投影到包含该日期的 K 线。日期没有已同步日线时仍可保存，列表提示缺少行情，暂不显示标记；日期或价格超出当前可视范围时标记也暂不显示。「定位」调整时间区间，不调整纵轴价格范围。

## 本地保存与 JSON 备份

- 保存在当前浏览器、当前站点的 localStorage，键为 `stock:observation-notes:v1`。不访问新数据源，不上传笔记，不跨浏览器或设备自动同步。
- 「导出全部笔记备份」下载 JSON，包含两只证券的全部笔记，不受当前查看区间影响。每条记录包含编号、证券、日期、可选价格、正文、创建与更新时间，文档包含格式版本和导出时间。
- 「导入笔记备份」校验后合并；同编号且同证券的笔记保留更新时间较新的内容，重复导入不会重复记录。相同更新时间保留已有记录。不同编号视为不同笔记，不按正文去重；导入不删除现有笔记。
- JSON 仅备份观察笔记，不包含既有画线或使用偏好。每条正文最多 2,000 字符，两只证券合计最多 1,000 条，导入文件最多 8 MB。
- 格式错误、非法日期／价格、未知证券、重复编号或超限备份整体拒绝，不部分写入。价格必须是正有限数；内容作为纯文本展示。
- 浏览器禁止存储或写入失败时提示修改仅留在页面中，此时仍能导出备份。已有存储损坏时保留原存储，不覆盖为新内容。遇到这类提示，应在离开或刷新页面前导出当前笔记。

清理浏览器站点数据、更换域名或端口都会影响本地记录的可见性。需要迁移时先导出 JSON，在目标站点导入。

## PNG 图表内容

「导出 PNG」下载当前 K 线图，包括证券代码／名称、日／周／月／季周期、K 线／折线、实际可见行情区间、东方财富来源、最新已同步日线日期、已同步日线历史范围、指标名称与参数，以及导出时间。

图像按两倍像素尺寸生成。全屏图保留当前副图、成交量，以及已完成且可见的画线；首页小图导出其实际显示内容。未完成画线、选中控制点和交互区域不导出。隐藏画线不导出。笔记保留可见 N 编号，页脚列出最多前 20 条可见笔记、每条前 80 字符；完整文本通过 JSON 备份保存。

查看区间采用已显示行情 K 线的实际起止日期，周／月／季图使用对应聚合区间；右侧空白栏不作为未来行情。行情数据日期采用原始日线日期，导出时间独立列出，不把导出当天当成行情日期。当前行情读取／采集失败提示会随图导出；波段信号另注明未来函数和历史重绘。

价格口径沿用原图：ETF 使用未复权价格，不含现金分红；指数为价格指数，不含分红再投资。本功能仅导出 K 线视图，不导出估值或回撤图。

## 实现与验证

- `src/utils/observationNotes.js`：笔记格式校验、备份合并、日线到聚合周期投影。
- `src/composables/useObservationNotes.js`：应用共享状态、本地保存、删除撤销和备份。
- `KLineNotesPanel.vue`／`KLineNotesOverlay.vue`：笔记编辑、位置选择、标记和键盘操作。
- `src/utils/chartExport.js`：导出元信息、SVG 样式固化、图表与覆盖层合成 PNG。
- `IndexChart.vue`、`useKlineChart.js`、`KLineDrawingTools.vue`：图表入口与当前图像／画线导出。

针对性验证：

```powershell
node --test tests/observationNotes.test.js tests/observationNotesComponent.test.js
```

测试覆盖本地重新读取、证券隔离、编辑删除撤销、备份合并／非法导入、存储失败保护、周期投影与缺失日期、实际查看区间、纯文本展示、位置价格精度、标记裁剪以及全屏 Escape／文本框焦点行为。浏览器实测已验证保存后刷新恢复、图上选择位置、JSON 下载／重复导入，以及带笔记的 PNG 实际下载和图像内容。
