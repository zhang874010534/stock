# 今日与我有关

首页顶部和侧栏提供「今日与我有关」。概览复用本页共享数据、当前浏览器的个人账本，以及观察提醒模块的实时计数，不新增数据请求、不触发上游采集。

## 五项概览

- 最新价格变化：当前证券最近已收盘交易日相较准确上一交易日的收盘变化。保留比较日期、最新价格和涨跌额；ETF 使用未复权价格，指数使用价格指数。缺少上一交易日、日历未覆盖或行情校验失败时不计算跨日涨跌。
- 持仓盈亏变化：仅适用于 512890。比较两个相邻交易日收盘时的账本累计盈亏，口径与个人账本一致：已实现交易盈亏 + 浮动盈亏 + 扣费后到账分红 − 其他费用。包含期间记账的买卖、拆分、费用与分红，清仓后仍显示已实现收益。第一笔交易前基准为零；新记录晚于行情时暂停比较。它不是简单的“当前份额 × 日涨跌”，也不是账户资金流调整后的收益率。
- 未读提醒：当前证券在本机保存的未读触发记录数量，同时展示满足与待核验的条件数。新增触发、全部标为已读、证券切换会立即同步；点击概览不会自动将记录标为已读。
- 最新成分变化：比较最近两次保存观察的调入、调出、更名及已有行业归属变化，展示实际名单日期和最新观察时间。首次记录只作基线；最新两次无变化时展示零，不回显更早的调样。相同来源日期的修订仍按观察顺序比较。ETF 展示标的指数名单，不代表基金实际持仓，也不能确认官方调样生效日。刷新失败时沿用成分详情保留的整组输入。
- 数据异常与待核验：汇总当前页面已使用来源的读取失败、后台失败、未知采集状态、旧数据、日历覆盖与各模块的覆盖异常，按目标模块合并计数。收益率历史分别使用股息率和国债序列的最新实际日期；收益风险时效使用计算截止日。正常来源日期差异不作为异常。

概览标题中的日期为北京时间当前日期，卡片中的比较区间为真实观察日期。休市日不会把最近已保存数据称为今日行情；盘中不使用当日尚未收盘的价格。页面每分钟更新时效判断，重新读取由现有首页按钮控制。

## 定位与状态

价格、账本、提醒和成分卡片直接定位对应模块并转移键盘焦点。成分卡片会将对比范围恢复为最近两次观察。异常卡片展开概览内的明细，每项链接继续定位相关模块；采集状态文件错误会打开原有后台状态详情。

空账本提示录入实际交易；指数页面说明个人账本适用 ETF。提醒尚未初始化和数据读取中有独立状态，加载完成前不声称全部正常。浏览器拒绝或损坏账本存储时，异常明细显示原账本警告并保留原存储。
