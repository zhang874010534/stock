# 自定义首页

入口在首页数据状态下方的「首页布局」，侧栏「自定义首页」也可定位。布局面板和全页数据状态始终显示，不参与模块隐藏。

## 使用

- 在「切换布局」选择默认全览、看行情、看持仓或做研究，也可选择当前证券的已保存布局。切换可撤销；恢复默认首页保留命名布局。
- 点击「自定义首页」展开设置，勾选显示／折叠，使用上移／下移调整顺序。各模块上方也提供折叠和隐藏按钮。全部隐藏后仍可从设置面板恢复。
- 输入 1–24 个字符的名称，点击「另存为新布局」保存当前排列，最多保存 20 个命名布局（两只证券合计）。当前证券的名称须唯一。
- 已保存布局是独立快照。之后的显示、折叠、排序调整会自动保存为当前排列，并显示「已调整」；点击「更新所选布局」才覆盖原快照，也可同时改名。重新选择该布局可恢复快照，切换可撤销。
- 删除所选布局保留当前排列，可在本页撤销最近一次删除。撤销只恢复命名布局，从列表重新选择即可应用；刷新页面后不保留撤销记录。

所有控件支持键盘操作，窄屏将模块选项换行排列。折叠按钮提供展开状态和关联区域，排序按钮说明目标模块并禁用首尾边界。

## 模块状态与定位

隐藏／折叠使用 `v-show` 保留已挂载模块，排序保留相同模块实例，因此表单草稿、筛选和图表当前查看状态保留。既有数据读取与提醒检查继续运行；这项功能用于信息取舍，不减少数据读取。证券切换仍遵循各模块原有的状态管理规则，刷新页面只恢复其原本支持保存的状态。

侧栏只列可见模块，顺序跟随首页，折叠模块带标记。从「今日与我有关」、提醒入口、K 线交易标记或其他本页锚点点击详情，自动显示并展开所属模块，滚动并聚焦目标。初始带模块锚点的链接及浏览器前进／后退也可恢复目标显示。首页「标的指数成分股／查看成分股」会先展开行情模块，再打开原有成分股详情。

自动展开会保存到当前排列；命名快照不变，需点击更新才保存这项变更。

## 保存与容错

布局保存在当前站点的 `localStorage`，键为 `stock:home-layouts:v1`，包含版本、两只证券的当前模块排列和命名布局快照。不跨设备同步。首页布局使用独立存储，不修改个人账本、提醒、笔记、图表偏好或画线；顶部「恢复默认偏好」仍作用于原有证券和图表偏好，布局使用自己的「恢复默认首页」。

读取时去除未知／重复模块，保留有效显示及折叠选择，新增模块补入末尾并默认显示。无效命名记录独立丢弃，不影响其他有效布局；根配置损坏或版本不支持时保留原存储，退回默认首页并提示本次调整仅在本页生效。写入受限或容量不足会显示保存失败，仍可操作当前页面。

## 实现与验证

- `src/utils/homeLayout.js`：模块注册表、预设、名称和版本校验、锚点映射。
- `src/composables/useHomeLayout.js`：独立持久化、按证券切换、命名快照、更新、删除及切换撤销。
- `HomeLayoutSettings.vue`、`HomepageModule.vue`：布局设置与保留状态的模块容器。
- `App.vue`、`AppSidebar.vue`、`Home.vue`：共享布局、模块渲染、可见导航、自动展开与定位。
- `tests/homeLayout.test.js`：预设、存储恢复、证券隔离、快照独立性、排序边界、删除冲突、无效配置及存储失败。
- `tests/homeStatus.test.js`：真实首页配置交互、切换恢复、组件实例保留、隐藏提醒草稿恢复与概览跳转。

验证命令：`npm test`、`npm run build`。2026-10-02 全量测试 371 项：370 项通过、1 项跳过；构建成功（保留现有产物体积提示）。浏览器验证记录及截图见 `artifacts/home-layout/README.md`。
