# 每周／每月复盘摘要

首页“成分与行业结构”之后提供复盘摘要，侧栏“每周／每月复盘”直达。H30269 与 512890 各自查看笔记和历史，复用首页行情、东方财富估值历史、中证成分历史及现有个人观察笔记，不新增采集接口。

## 生成与保存

周复盘为周一至周日，选择该周任意一天；月复盘为自然月，默认月份为上一个自然月。点击“上一周期”向前选择，点击“生成复盘”生成一份摘要。未来尚未开始的周期不能生成；当前周期标为进行中，个人笔记截至北京时间今日，行情只使用已收盘交易日，当日 15:00 前回退到前一交易日。

摘要包含六项指标、成分观察变化、区间内该证券的个人笔记和最多 4000 字复盘感想。512890 复盘还自动读取共享个人账本，加入买卖、费用、分红和个人盈亏变化，无需再次录入。笔记按其记录日期筛选，周末笔记也保留；不把另一只证券的笔记混入。笔记编辑入口仍在 K 线的“观察笔记”，更新笔记或账本后重新生成才能纳入新内容。

点击“保存本次复盘”将全部指标、说明、账本及估值端点、笔记全文、感想、区间和生成时间保存为独立快照。后续行情回补、估值更新、成分变化、账本或笔记编辑不会改动已保存内容。历史可查看、导出、删除及撤销最近一次删除。“另存修改版本”沿用原数据快照，仅修改感想后另存一份；如需更新指标、账本和笔记，重新生成新稿。同周期允许保存多个版本，不覆盖旧稿。旧版历史仍可读取，并提示未包含账本快照，不将当前账本补进历史。

## 账本与复盘联动

ETF 复盘的“我的账本与盈亏”展示本期买入支出（含买入费）、卖出回款（扣卖出费）、全部费用、实际到账分红（扣分红费）、其他费用、已实现交易盈亏变化、浮动盈亏变化和个人累计盈亏变化。金额为元，不把投入或市值变化当作收益率。按自然日期统计本期账本，周末的费用或分红也纳入；期后记录不进入快照。H30269 复盘不显示 ETF 私人交易。

移动加权平均成本从第一笔实际记录起重放，包括本期之前的成本和已实现盈亏；期初为本期开始前的持仓状态，期末为汇总截止日的状态。期初使用区间前一交易日收盘，期末使用截至截止日最近应已收盘交易日的准确价格（北京时间当日 15:00 前排除当日），分别显示估值日期。个人累计盈亏变化 = 期末累计盈亏 − 期初累计盈亏 = 已实现交易盈亏变化 + 浮动盈亏变化 + 扣费后分红 − 其他费用。买卖费用已经计入成本或已实现盈亏，分红扣费已计入到账金额，全部费用卡供核对，不能再次减去。

首次买入前没有持仓，期初市值和盈亏为零；清仓端点无需行情估值。没有本期交易但已有持仓，仍展示收盘估值导致的盈亏变化。尚无可用账本时显示录入提示，不报告默认零收益。行情缺少准确估值端点或日历未覆盖时，相关变化显示“—”及原因，本期现金流、已实现盈亏和费用仍可核算；不回退到更旧的价格填补缺口。收盘之后或休市期间的买卖／份额调整导致持仓改变时，不使用旧收盘价估值新持仓；单纯费用或现金分红仍可计入已知持仓盈亏。账本读取／保存异常会随摘要及导出提示完整性无法确认。

展开“交易明细与同日观察”查看本期全部记录，按日期及同日顺序排列，保留成交份额与价格、成交金额、费用、现金流、交易盈亏和账本备注。买入与卖出自动匹配同证券、同记录日期的全部观察笔记，展示笔记全文、可选记录价格和创建／更新时间。笔记晚于交易日创建时标为“后来补记”，编辑过的笔记标为“已修改，原始判断未保存”。现有记录没有成交时刻，因此同日关联不能确认笔记在成交前写下，也不推测未记录的交易理由。

本机快照保存截至该周期的完整已录入账本，以便恢复历史成本；页面及 PNG／Markdown 仅展示本期交易明细和两端持仓摘要，不展开以前周期的交易备注。复盘里的“查看／补录账本”跳转到现有个人账本模块。

## 指标口径

| 指标 | 计算与缺失处理 |
| --- | --- |
| 区间价格收益 | 期末收盘 ÷ 区间前一交易日收盘 − 1，包含区间首个交易日的收益；完整核验基准至期末每个交易日 |
| 回撤变化 | 期末回撤正数跌幅减期初回撤跌幅，单位为百分点；负值表示回撤减轻，各日高点仅用截至当日全部已同步收盘 |
| 60 日波动率变化 | 期末减期初的 60 日年化波动率，单位为百分点；每端需要 61 个连续交易日收盘，简单日收益率样本标准差 × √252 |
| 指数 PE / PB 变化 | 区间内最新估值观察减区间开始前最新观察，显示两端实际源日期；缺期初观察时保留期末值说明，变化显示“—” |
| 区间最大回撤 | 区间前一交易日至期末的收盘路径最大跌幅，高点限于该路径，区别于全历史最大回撤 |

不以区间第一个收盘当期初收益基准，不缩短区间来规避缺日，不填补行情或波动率窗口。自然休市不计交易日，日历覆盖范围外的价格指标不可核验。尚无已收盘交易日的周期仍可汇总个人笔记，价格指标显示原因。

ETF 使用未复权场内价格，不含实际现金分红；除息和份额拆分可能影响价格、回撤和波动率。指数使用价格指数，不含分红再投资。区间价格收益不是个人交易账本或个人账户收益。ETF 的 PE/PB 和成分为 H30269 标的指数，估值仅用东方财富独立口径，不混用中证估值，不使用区间之后的观察。

## 成分变化

使用区间前最近保存观察与区间内最近观察比较，展示净新增、净移除、更名及可识别的已分类行业归属变化，并列出新增／移除股票。另汇总已保存路径的调入／调出次数，同一股票反复出现可多次计数，避免净变化为零时隐藏已观察的中间变化。

缺少区间前观察时不报告净变化，首次名单只作基线。源日期和采集观察时间各自保留；两个快照之间未采集的变化未知，不能确认官方调样生效日。行业缺失或保留值会说明，分类补充和修订不冒充调样。ETF 的标的指数成分不是基金实际持仓。

## 数据状态与导出

任一来源读取失败时，其他通过身份和格式校验的项目仍能汇总；如果使用页面保留数据，会在摘要与导出中明确记录。无效来源或样本不足显示“—”及原因，不返回默认零值。历史价格分析不强制所有来源最新日期相同，估值、成分保留其实际观察日期，不插值对齐。

支持 PNG 图片和 Markdown，均包含全部指标、本期账本明细和盈亏、交易同日观察、成分说明、个人笔记全文、感想、数据状态与口径。PNG 使用本机 Canvas 直接绘制，无外部图片或截图依赖；超过单张图片的内存／尺寸限制时明确提示导出 Markdown，不静默截断笔记。Markdown 对个人文本的 HTML、链接和格式符号作转义，保持文本内容而不执行用户笔记中的 HTML。导出由用户主动点击，浏览器决定下载位置。

历史在当前站点的 localStorage 中，以 `stock:review-summaries:v1`、schemaVersion 1 保存，最多 50 份，由两只证券共享容量。损坏或不支持的历史保存格式不覆盖原内容，当前新稿仍可临时保存并导出；写入失败明确提示仅留在页面中。没有后台定时生成、跨设备同步或自动对外发送。
